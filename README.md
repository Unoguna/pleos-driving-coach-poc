# Pleos Driving Coach PoC

Pleos Connect SDK를 활용하여 **초보 운전자를 위한 '나의 운전선생님' 서비스의 기술적 구현 가능성을 검증**하는 프로젝트입니다.

실제 서비스 개발에 앞서 필요한 차량 데이터에 접근할 수 있는지, 각 기능을 구현할 수 있는지, 기술적으로 어떤 제약이 있는지 확인하는 것을 목표로 합니다.

## 검증 방법

각 기능은 다음 절차에 따라 검증합니다.

1. **SDK 지원 확인:** Pleos 공식 문서에서 필요한 API 및 데이터 제공 여부 확인
2. **데이터 접근 테스트:** Pleos Emulator에서 실제 데이터 조회 가능 여부 확인
3. **기능 구현 테스트:** 최소한의 기능을 구현하여 정상 동작 여부 확인
4. **결과 기록:** 구현 가능 여부와 기술적 제약사항 정리

실제 차량 데이터 접근이 불가능한 경우 가상 데이터를 활용하여 분석 기능을 별도로 테스트합니다.

## 검증 결과 기준

| 상태 | 설명 |
|---|---|
| Verified | 실제 SDK 또는 Emulator에서 동작 확인 |
| Partial | 일부 기능 구현 가능, 제약사항 존재 |
| Mock Only | 가상 데이터로만 기능 검증 |
| Unsupported | 현재 환경에서 구현 불가능함을 확인 |
| Not Tested | 아직 검증하지 않음 |
