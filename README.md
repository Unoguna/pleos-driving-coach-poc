# Pleos Driving Coach PoC

Pleos Connect SDK를 활용하여 **초보 운전자 코칭 서비스의 주요 기능에 대한 기술적 구현 가능성을 검증**하는 프로젝트입니다.

실제 서비스 개발에 앞서 필요한 차량 데이터의 접근 가능 여부, SDK 지원 범위, 기능별 구현 방식 및 기술적 제약사항을 확인하는 것을 목표로 합니다.

## 기술 검증 항목

### 1. 차량 데이터 수집 (Vehicle Data)

- [ ] 차량 속도 데이터 조회
- [ ] 조향각 데이터 조회 및 변화량 측정
- [ ] 가속도 및 제동 데이터 조회
- [ ] 수직 가속도 및 차량 충격 감지
- [ ] 주행·정차·주차 상태 감지
- [ ] 사이드미러 상태 조회
- [ ] 차량 경고등 및 진단 정보 조회

### 2. 운전 습관 분석 (Driving Behavior Analysis)

- [ ] 과도한 핸들 조작 감지
- [ ] 급출발 및 급가속 감지
- [ ] 급정거 및 급제동 감지
- [ ] 과속방지턱 통과 시 과도한 충격 감지
- [ ] 주행 이벤트 기록 및 분석

### 3. 주행 안내 (Driving Assistance)

- [ ] 기존 내비게이션과 연동 가능 여부 확인
- [ ] 목적지 및 주행 경로 정보 조회
- [ ] 쉬운 길 우선 경로 탐색 가능성 검증
- [ ] 진출입로 및 합류 구간 사전 안내
- [ ] 회전교차로 접근 및 통행 안내
- [ ] 실시간 교통량 및 도로 혼잡도 정보 조회

### 4. 운전 연수 (Driving Training)

- [ ] 현재 위치 기반 연수 코스 탐색
- [ ] 도로별 제한속도 및 교차로 정보 조회
- [ ] 교통량 및 도로 복잡도를 고려한 난이도 평가
- [ ] 난이도별 연수 코스 추천
- [ ] 안전 운전 미션 달성 여부 판정
- [ ] 미션 점수 산정

### 5. 차량 상태 알림 (Vehicle Monitoring)

- [ ] 출발 시 사이드미러 접힘 상태 감지
- [ ] 차량 경고등 점등 이벤트 감지
- [ ] 경고등 종류 및 의미 식별
- [ ] 차량 상태에 따른 알림 출력

### 6. 음성 코칭 (Driving Coaching)

- [ ] TTS 기반 음성 안내
- [ ] 주행 이벤트 발생 시 음성 피드백
- [ ] 운전 선생님 성향에 따른 안내 문구 변경
- [ ] 음성 종류 및 말하기 속도 변경
- [ ] 내비게이션 음성과 동시 사용 가능 여부 확인
- [ ] 주행 중 음성 안내 빈도 제어

### 7. 주행 리포트 (Driving Report)

- [ ] 주행 시작 및 종료 시점 감지
- [ ] 주행 데이터 및 이벤트 저장
- [ ] 주정차 후 음성 요약 제공
- [ ] 주행 종료 후 통계 및 리포트 생성
- [ ] MyHyundai 등 외부 앱 연동 가능성 확인

### 8. 플랫폼 및 확장 기능 (Platform & Extensions)

- [ ] 백그라운드 주행 데이터 수집
- [ ] 주행 중 최소 UI 및 플로팅 알림 표시
- [ ] Pleos Emulator에서 기능별 테스트
- [ ] 전방·후방 카메라 데이터 접근 가능 여부 확인
- [ ] ADAS 데이터 접근 가능 여부 확인

## 검증 방법

각 기능은 다음 순서로 검증합니다.

1. **SDK 지원 확인:** 공식 문서에서 관련 API 및 권한 확인
2. **데이터 접근 테스트:** Emulator에서 실제 데이터 조회 및 이벤트 수신
3. **기능 구현 테스트:** 수집한 데이터를 활용한 최소 기능 구현
4. **결과 기록:** 구현 가능 여부 및 제약사항 문서화

SDK에서 지원하지 않는 데이터는 Mock 데이터를 활용해 분석 로직을 별도로 검증합니다. Mock 데이터로 성공한 기능은 실제 차량 연동 성공과 구분하여 기록합니다.

## 검증 결과 기준

| 상태 | 의미 |
|---|---|
| ✅ Verified | SDK 또는 Emulator에서 실제 동작 확인 |
| 🟡 Partial | 일부 구현 가능하나 제약 존재 |
| 🔵 Mock Only | 가상 데이터 기반 기능 검증 |
| ❌ Unsupported | 현재 환경에서 구현 불가 확인 |
| ⬜ Not Tested | 미검증 |
