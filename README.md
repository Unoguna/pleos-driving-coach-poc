# 🚗 Pleos Driving Coach PoC

Pleos Connect SDK를 활용하여 **'나의 운전선생님' 서비스의 기술적 구현 가능성을 검증**하는 프로젝트입니다.

실제 서비스 개발에 앞서 각 기능에 필요한 차량 데이터의 접근 가능 여부, SDK 지원 범위, 구현 방식 및 기술적 제약사항을 확인하는 것을 목표로 합니다.

## 🔬 기술 검증 항목

### 1. 차량 데이터 수집 (Vehicle Data)

운전 코칭에 필요한 차량 데이터의 접근 가능 여부를 검증합니다.

- [ ] 차량 속도 데이터 조회
- [ ] 조향각 데이터 조회 및 변화량 측정
- [ ] 가속도 및 제동 관련 데이터 조회
- [ ] 수직 가속도 및 차량 충격 데이터 조회
- [ ] 주행·정차·주차 상태 조회
- [ ] 사이드미러 접힘 상태 조회
- [ ] 차량 경고등 및 진단 정보 조회

### 2. 운전 습관 분석 (Driving Behavior Analysis)

수집한 차량 데이터를 활용하여 운전자의 주행 습관을 분석할 수 있는지 검증합니다.

- [ ] 과도하거나 불필요한 핸들 움직임 감지
- [ ] 급출발 및 급가속 감지
- [ ] 급정거 및 급제동 감지
- [ ] 과속방지턱 통과 시 과도한 충격 감지
- [ ] 감지된 운전 습관에 따른 조언 생성

### 3. 주행 안내 (Driving Assistance)

내비게이션 및 도로 정보를 활용한 초보 운전자 맞춤형 안내 기능의 구현 가능성을 검증합니다.

**쉬운 길 안내**
- [ ] 기존 내비게이션과 연동 가능 여부 확인
- [ ] 자체 내비게이션 도입 가능성 검토
- [ ] 운전 난이도가 낮은 경로 탐색 가능 여부 확인

**진출입로 사전 안내**
- [ ] 진출입로 및 합류 구간 정보 조회
- [ ] 교통 정체 구간 인식
- [ ] 진출입로 진입 전 차로 변경 준비 안내
- [ ] 주변 차량 밀집도를 고려한 사전 안내 가능성 검증

**회전교차로 안내**
- [ ] 회전교차로 위치 및 진입 정보 조회
- [ ] 회전교차로 주행 방법 음성 안내

### 4. 운전 연수 (Driving Training)

운전자의 숙련도에 맞는 연수 코스를 제공하고, 주행 중 미션을 수행할 수 있는지 검증합니다.

**난이도별 운전 연수**
- [ ] 현재 위치 기반 주변 연수 코스 탐색
- [ ] 주변 차량 밀집도 및 교통량 정보 조회
- [ ] 횡단보도 및 교차로 정보 조회
- [ ] 도로별 최고·최저 제한속도 정보 조회
- [ ] 초급·중급·고급 난이도별 연수 코스 추천

**주행 미션 및 점수**
- [ ] 주행 중 미션 부여
- [ ] 부드러운 출발 및 정차 미션
- [ ] 안정적인 핸들 조작 미션
- [ ] 차선 변경 수행 여부 감지 가능성 확인
- [ ] 속도 변화 및 감속 수행 여부 감지 가능성 확인
- [ ] 미션 달성 여부 판정 및 점수 부여

※ 원안의 차선 변경 10회, 80km/h 이상 가속 후 감속 등은 기술적 감지 가능성만 검증합니다. 실제 주행에서 불필요한 차선 변경이나 과속을 유도하는 미션은 제공하지 않습니다.

### 5. 차량 상태 알림 (Vehicle Status Monitoring)

차량 상태 데이터를 활용하여 운전자에게 필요한 정보를 안내할 수 있는지 검증합니다.

**사이드미러 알림**
- [ ] 사이드미러 접힘 상태 감지
- [ ] 출발 시 사이드미러가 접혀 있는 경우 알림 출력

**경고등 안내**
- [ ] 차량 경고등 점등 이벤트 감지
- [ ] 경고등 종류 및 의미 식별
- [ ] 경고등에 대한 설명 제공

### 6. 음성 코칭 (Driving Coaching)

주행 중 운전자에게 음성으로 피드백을 제공하고, 운전 선생님의 성향을 설정할 수 있는지 검증합니다.

**실시간 음성 피드백**
- [ ] TTS 기반 음성 안내
- [ ] 운전 습관 분석 결과에 따른 음성 조언
- [ ] 주행 상황에 따른 음성 안내
- [ ] 내비게이션 음성과의 동시 사용 가능 여부 확인
- [ ] 주행 중 불필요한 음성 안내 최소화

**운전 선생님 성향 설정**
- [ ] 부드러운 강사 스타일
- [ ] 엄격하거나 호통치는 강사 스타일
- [ ] 운전 선생님 성향에 따른 안내 문구 변경

**목소리 선택**
- [ ] 음성 종류 및 말하기 방식 변경
- [ ] 사투리 음성 적용 가능성 확인
- [ ] 연예인·배우·아이돌 음성 적용 가능성 확인
- [ ] 뽀로로·짱구 등 캐릭터 음성 적용 가능성 확인

※ 특정 인물 및 캐릭터 음성의 실제 사용에는 권리자의 허락이나 적절한 라이선스가 필요합니다.

### 7. 주행 리포트 (Driving Report)

주행 중 수집한 데이터를 분석하여 운전자에게 리포트를 제공할 수 있는지 검증합니다.

**주정차 시 음성 리포트**
- [ ] 주행 및 정차·주차 상태 감지
- [ ] 해당 주행의 운전 습관 분석 결과 요약
- [ ] 주정차 시 간략한 음성 리포트 제공

**하차 후 상세 리포트**
- [ ] 주행 데이터 및 분석 결과 저장
- [ ] 주행 종료 후 상세 리포트 생성
- [ ] 별도 모바일 앱에서 리포트 조회 가능성 검증
- [ ] MyHyundai 앱 연동 가능성 확인

### 8. 플랫폼 및 UI (Platform & UI)

Pleos 환경에서 주행 중 앱 실행 및 최소한의 사용자 인터페이스를 제공할 수 있는지 검증합니다.

**백그라운드 실행**
- [ ] 앱 실행 후 주행 중 백그라운드 동작
- [ ] 백그라운드에서 차량 데이터 수집
- [ ] 주행 중 화면 표시 최소화

**주행 중 UI**
- [ ] 화면 상태바를 활용한 알림 표시 가능 여부 확인
- [ ] 우측 상단 플로팅 UI 구현 가능 여부 확인
- [ ] 주행 중 음성 및 팝업 안내
- [ ] 주행 중 사용자 조작 최소화

## 🧪 검증 방법

각 기능은 다음 절차에 따라 검증합니다.

1. **SDK 지원 확인:** Pleos 공식 문서에서 관련 API와 접근 권한 확인
2. **데이터 접근 테스트:** Emulator에서 차량 데이터 조회 및 이벤트 수신
3. **기능 구현 테스트:** 최소 기능 구현을 통한 동작 검증
4. **결과 기록:** 구현 가능 여부, 제약사항 및 테스트 결과 문서화

실제 차량 데이터 접근이 불가능한 경우 Mock 데이터를 활용하여 분석 로직을 별도로 검증합니다.

### 검증 결과 기준

| 상태 | 설명 |
|---|---|
| ✅ Verified | 실제 SDK 또는 Emulator에서 동작 확인 |
| 🟡 Partial | 일부 구현 가능하나 제약사항 존재 |
| 🔵 Mock Only | 가상 데이터 기반 기능 검증 |
| ❌ Unsupported | 현재 환경에서 구현 불가 확인 |
| ⬜ Not Tested | 검증 전 |
